# 無線通訊指標：CSI 與 RSSI[[English]](../en/Wireless-indicators-CSI-and-RSSI.md) [[简体中文]](../zh_CN/Wireless-indicators-CSI-and-RSSI.md)

在無線通訊中，Channel State Information (CSI) 與 Received Signal Strength Indicator (RSSI) 是評估無線訊號品質與特性的重要指標。

## CSI (Channel State Information)

CSI 為無線通訊系統中描述通道特性的詳細資訊，包含通道的幅度與相位，常以頻域中的複數向量表示。CSI 能精確描述通道狀態，廣泛應用於 Multiple Input Multiple Output (MIMO) 與 Orthogonal Frequency Division Multiplexing (OFDM) 系統。

### 優點

1. **高精度：** CSI 提供詳細通道資訊，包括訊號幅度與相位，能精準描述通道狀態。
2. **支援進階訊號處理：** CSI 的細緻資訊可支援 Beamforming、Precoding 與 MIMO 通訊等進階技術，顯著提升系統效能。
3. **動態調整能力：** 即時 CSI 資訊可動態調整傳輸策略與參數，增進通訊可靠度與效率。

### 缺點

1. **高複雜度：** 取得與處理 CSI 需要大量運算資源與複雜硬體支援。
2. **高度時變：** CSI 容易受到通道變化影響，需頻繁更新以維持準確度。
3. **開銷較高：** 蒐集與傳輸 CSI 會增加系統開銷，尤其在高速移動環境中更為明顯。

## RSSI (Received Signal Strength Indicator)

RSSI 用於量測接收到的無線訊號強度，通常以 dBm（分貝毫瓦）表示。RSSI 為純量值，直接反映訊號功率大小，並不包含詳細的通道特性。

### 優點

1. **簡單易用：** RSSI 的量測與處理相對簡單，不需複雜計算或硬體支援。
2. **低開銷：** RSSI 量測不需大量系統資源，適合資源受限的裝置與應用。
3. **應用廣泛：** RSSI 常見於 WLAN、行動網路與 IoT 等場域，用於訊號品質評估與定位。

### 缺點

1. **精度較低：** RSSI 只提供訊號強度資訊，無法反映通道細節，精度有限。
2. **易受干擾：** RSSI 對多重路徑效應、干擾與雜訊敏感，量測結果易偏差。
3. **不利於進階技術：** RSSI 無法支援進階訊號處理，在複雜通訊環境較難優化效能。

## 總結

- **細節層級：** CSI 提供更完整的無線通道資訊，包括幅度、相位與頻率響應；RSSI 則僅給予訊號強度的粗略量測。
- **應用情境：** Wi-Fi CSI 尤其適合需要細緻分析無線通道的進階應用，如室內定位、手勢辨識與活動偵測；RSSI 則常用於訊號強度估測等基礎任務。
- **精度比較：** 在部分應用中，CSI 能提供比 RSSI 更高的定位、追蹤與動作判別精度。
- **硬體需求：** 雖然一般 Wi-Fi 接收器都能取得 CSI 與 RSSI，CSI 需要較進階的硬體能力來擷取與處理詳細通道資訊；RSSI 則是較簡單的量測方法，多數 Wi-Fi 接收器皆可使用。

|  | **CSI** | **RSSI** |
| ---- | ---- | ---- |
| **資訊類型** | 詳細通道特性（幅度、相位） | 訊號強度 |
| **精度** | 高 | 低 |
| **運算複雜度** | 高 | 低 |
| **動態調整能力** | 強 | 弱 |
| **硬體開銷** | 高 | 低 |
| **應用情境** | 適合 MIMO、Beamforming 等進階訊號處理 | 適合資源受限與基本訊號品質評估 |

在實務應用中，CSI 與 RSSI 各有其適用範疇：CSI 適合需要精準通道資訊與進階訊號處理的系統；RSSI 則適合需求簡單、資源有限的應用。
